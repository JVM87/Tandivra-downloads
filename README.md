# Tandivra downloads

Public Windows companion downloads, installation instructions and privacy policy.

Website: https://jvm87.github.io/Tandivra-downloads/

Download the latest Windows ZIP under Releases, extract all files and run Tandivra.Server.exe. Requires Windows 11 x64 and Bluetooth. Preview binaries are unsigned. Android access uses Google Play closed testing; contact seikenjvm@hotmail.com.

The private application source and signing keys are not included in this repository.
